[高危] MySQL 3306 监听 0.0.0.0 未限制外网访问 CIS-NET-01

数据库端口直接暴露于公网，未开启 UFW 白名单，易遭受暴力破解和未授权碰撞攻击。

整改措施: 修改 mysqld.cnf bind-address = 127.0.0.1，并通过 SSH 隧道或受控网关访问。
[高危] SSH 允许 root 密码远程直连 CIS-SEC-04

服务器 SSH 配置开启了 PermitRootLogin yes，且允许口令登录，未强制私钥密钥对认证。

整改措施: 修改 /etc/ssh/sshd_config 设 PermitRootLogin prohibit-password 并 reload sshd。
[警告] payment-worker 容器触发 OOM 重启 SRE-SVC-02

最近 24 小时内容器发生 1 次内存溢出被 Linux 内核 Killer 杀掉（Exit 137）。

整改措施: 调高 compose 中的 mem_limit 从 512M 至 1024M，或开启 JVM MaxRAMPercentage 调优。
