根因：PHP-FPM 或 Node 进程池打满，导致 upstream 连接队列溢出。处置流程：先抓取当前连接统计，再逐步平滑提升 worker 进程并重载。

1. netstat -s | grep overflow
2. systemctl status php-fpm || pm2 list
3. safe_reload_service(nginx)
适用主机: Linux 全系
