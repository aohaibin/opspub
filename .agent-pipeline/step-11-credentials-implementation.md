# 第 11 步 · 服务凭据实现回执

## 实现

- `#/credentials` 沿用「安全与治理 → 服务凭据」入口。工作区提供按服务器、地址搜索和按分组筛选的列表。详情仅显示资产元数据、认证方式、托管状态和验证历史。
- 「添加凭据」从现有未托管 SSH 资产中选择目标。验证沿用现有 IPC 和首次连接的主机指纹确认流程，由 Rust 执行托管。密码、私钥路径和口令输入保持遮蔽。SSH Agent 与远程桌面保留各自状态和入口。
- 刷新分别读取资产和托管 ID，读取失败时显示错误，托管状态不可用时暂停凭据变更。忘记流程按单台服务器确认，等待后端删除响应并重新读取状态。删除凭据后保留资产及验证历史。
- 改动限定在 `ServerCredentialsPage.tsx`、`SshConnectModal.tsx` 和 `src/store/ssh.ts`。验证对话框的专用模式仅由凭据页启用。复用现有数据、IPC 和系统凭据管理器，Rust 与敏感库均无改动。
